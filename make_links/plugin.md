# Ссылки на главную в новостях

`make_links` — фильтр новостей, который находит слова из заданного списка в кратком или полном тексте и оформляет их ссылками на главную страницу сайта. Плагин не изменяет данные новости в базе: ссылка добавляется только при формировании текста страницы.

## Назначение и область работы

Фильтр включается отдельно для:

- главной страницы;
- страниц категорий;
- полной страницы новости.

Ссылки добавляются в текстовые переменные `short-story` и `full-story` в зависимости от выбранного режима отображения. Ссылка ведёт на адрес сайта `home`; настроить индивидуальный адрес для каждого слова нельзя.

## Настройка

Откройте настройки плагина в разделе `extra-config`.

| Параметр | Назначение |
|---|---|
| Добавлять ссылки на главной странице | Разрешает обработку списка новостей на главной. |
| Добавлять ссылки в категориях | Разрешает обработку списка новостей в категориях. |
| Добавлять ссылки на странице новости | Разрешает обработку полной страницы новости. |
| Максимум ссылок на странице | Общий верхний предел ссылок за текущий вывод страницы. Значение `0` отключает добавление ссылок. |
| Использовать полный текст при просмотре списка | Разрешает фильтру также обработать полный текст новости при выводе списка. |
| Использовать краткий текст на странице новости | Разрешает фильтру также обработать краткий текст на полной странице. |
| Перемешивать порядок слов | Перемешивает список слов перед обработкой каждой новости. |
| Слова для ссылок | Список искомых слов, разделённых запятыми. |

Настройки сохраняются в параметрах плагина: `if_main`, `if_category`, `if_full_news`, `max_link_count`, `mode_short`, `mode_full`, `if_rand_word` и `words`.

## Правила поиска

- Список разделяется запятыми; пробелы вокруг каждого элемента удаляются.
- Пустые элементы игнорируются.
- Поиск чувствителен к регистру.
- Совпадение ищется только после обычного пробела. Слово в начале текста или сразу после знака пунктуации может не совпасть.
- Уже существующие ссылки `<a>` и изображения `<img>` не изменяются.
- Найденное слово заменяется на HTML-ссылку с адресом `home`; отображаемый текст экранируется.
- Фильтр обрабатывает одну ссылку на найденное вхождение за проход, распределяя `max_link_count` между новостями текущего списка.

Пример списка:

```text
NGCMS, новости, портал
```

## Взаимодействие с другими фильтрами

Плагин подключён к фильтру `news`. Если одновременно используется `text_replace` и в обоих плагинах настроено одно и то же слово, ссылка, созданная первым обработчиком, пропускается следующим. Для одного и того же слова настройте только один плагин, чтобы результат не зависел от порядка фильтров.

## Реализация и совместимость

- Обработчик новостей: `news.php`.
- Страница настроек использует Twig-шаблон `tpl/config/config.tpl`.
- Локализация настроек находится в `lang/russian/config.ini` и `lang/english/config.ini`.
- Плагин не создаёт таблиц и не требует установки или удаления схемы базы данных.
- Для Twig-настроек требуется сборка NGCMS не ниже `2020731`.
