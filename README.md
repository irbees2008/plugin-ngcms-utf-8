# plugin-ngcms-utf-8

В этом репозитории собраны плагины NGCMS в кодировке UTF-8. Здесь есть плагины разных поколений: не все они совместимы с актуальной версией движка, а у некоторых есть замены. Перед установкой проверяйте требования и совместимость в документации конкретного плагина.
