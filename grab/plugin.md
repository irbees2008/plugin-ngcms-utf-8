 Плагин Grabber для NGCMS
Этот плагин позволяет парсить новости с других сайтов и автоматически добавлять их в вашу NGCMS.
Ниже — подробное руководство по установке, настройке и использованию.
==================================================================
📥 Установка
Скачайте архив с плагином.
Распакуйте в папку /engine/plugins/.
Активируйте плагин в админке:
Админ-панель → Плагины → Grabber → Активировать.
==================================================================
⚙️ Настройка
1. Основные параметры
Перейдите:
Админ-панель → Дополнения → Grabber

Здесь укажите:
URL страницы (например, https://example.com/news/some-article)
Селектор заголовка (CSS-путь, например, h1.article-title)
Селектор контента (CSS-путь, например, .article-content)

2. Примеры селекторов
Элемент	Пример селектора
Заголовок	h1, .title, #news-headline
Контент	.text, #content, div.article-body
3. Проверка парсинга
Нажмите "Тест", чтобы убедиться, что плагин корректно извлекает данные.
==================================================================
🛠️ Использование
1. Парсинг и добавление новости
Вставьте URL статьи.
Укажите селекторы.
Нажмите "Сохранить" → "Создать новость".
Выберите категорию и подтвердите добавление.
2. Логирование
Плагин сохраняет отладочную информацию в:
/engine/plugins/grab/debug_last_request.txt
==================================================================
🔧 Возможные проблемы и решения
❌ Новость не парсится
Проверьте селекторы (используйте DevTools в браузере).
Убедитесь, что нет JS-загрузки контента (плагин работает с исходным HTML).

❌ Новость не добавляется в базу
Проверьте права доступа к БД.
Убедитесь, что выбрана категория.
Проверьте логи PHP (error_log).

❌ Ошибка "Call to undefined function translit()"
Замените в config.php:
$newsData['alt_name'] = translit($grab_h1);  
На:
$newsData['alt_name'] = mb_strtolower(makeAlias($grab_h1));
