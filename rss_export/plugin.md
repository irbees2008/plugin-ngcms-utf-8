# RSS-экспорт новостей

Плагин экспортирует новости в формате RSS 2.0 с расширенными настройками. Можно публиковать общую ленту и ленту отдельной категории.

По умолчанию формируется основная RSS‑лента сайта по всем утверждённым новостям,
отображаемым на главной странице.

## URLs и примеры

### ЧПУ включены (SEO)

- Полная лента: `https://<ваш-домен>/rss.xml`.
- Лента категории `test`: `https://<ваш-домен>/test.xml`.

### ЧПУ выключены (non-SEO)

- Полная лента: `https://<ваш-домен>/plugin/rss_export/`.
- Лента категории `test`: `https://<ваш-домен>/plugin/rss_export/category/?category=test`.

Для non-SEO варианта у обработчика `category` нужен завершающий слеш перед параметрами (`/category/`), иначе возможен ответ 404.

## Настройки

Раздел админки: «Плагины» → `rss_export`.

### Общие

- Формат заголовка ленты (`site`, `site+category`, `handy`).
- Собственный заголовок (для формата `handy`).
- Формат заголовка новости: только название или «Категория :: Название».
- Количество новостей (`news_count`).
- Обработка `[hide]...[/hide]`.
- Состав контента: короткая и длинная новости, только короткая или только длинная.
- Обрезка контента (`truncate`; `0` — без обрезки).
- Отсрочка публикации в ленте (`delay`, в минутах).

### Enclosure (интеграция с XFields)

- Включение генерации enclosure по полю XFields.
- Выбор поля XFields. Поле типа `images` поддерживает автоматическую подстановку изображения.

### Кеширование

- Включение кеширования.
- Период обновления кеша в секундах.

## Поведение и совместимость

- Контент ленты очищается от `<script>`, `<iframe>`, опасных inline-стилей и обработчиков событий. Относительные ссылки в `src` и `href` преобразуются в абсолютные.
- Заголовки новостей выводятся как XML-текст: HTML-сущности декодируются, HTML-теги удаляются, а спецсимволы корректно экранируются.
- В канал добавляется `atom:link rel="self"` с фактическим URL текущего запроса.
- Абсолютные ссылки ленты и enclosure формируются из адресов сайта и файлов, заданных в конфигурации. Для внешней проверки используйте публичное доменное имя, а не локальный хост вроде `https://it`.
- MIME-тип enclosure для изображений определяется по расширению файла (`.png` → `image/png`, `.jpg`/`.jpeg` → `image/jpeg`); для неизвестного расширения используется `application/octet-stream`.
- Заголовок ответа: `Content-Type: application/rss+xml; charset=utf-8`.
- Если клиент поддерживает gzip и доступно расширение zlib, тело ленты сжимается; ответ также содержит `Vary: Accept-Encoding`.
- Для проверки актуальности ленты передаются `ETag` и `Last-Modified`. Условный запрос с `If-None-Match` или `If-Modified-Since` может получить пустой ответ `304 Not Modified`.
- Для категории используется её `alt`-имя, а не числовой ID.
- Поддерживается PHP 8; устранены ранние уведомления и проблемы с буферизацией вывода.

## Известные ограничения

- Лента формируется для одной категории за раз.
- Для enclosure из XFields типа `images` указывается тип `image/jpeg`; для остальных типов используется `application/octet-stream`.

## Ссылка на категорийную ленту без ЧПУ

Используйте `/plugin/rss_export/category/?category=<alt_имя_категории>` с завершающим слешем после `category/`.
