# =========================================================================== #
# Show Comments
# =========================================================================== #

Административный плагин для просмотра и управления комментариями к опубликованным новостям.

## Возможности

- Постраничный список комментариев со ссылками на новость и административные действия.
- Сортировка по ID комментария по возрастанию или убыванию.
- Усечение текста комментария с сохранением HTML-разметки.
- Массовое удаление выбранных комментариев.
- Пересчёт счётчиков комментариев у новостей и пользователей после удаления.

Плагин использует таблицы комментариев и новостей NGCMS и требует установленный плагин `comments`. Собственные таблицы не создаются.

## Настройки

| Параметр | Описание | По умолчанию |
|---|---|---:|
| Количество комментариев на странице | Размер страницы списка | 5 |
| Длина комментария | Максимальная длина фрагмента, допустимый диапазон 10–5000 символов | 50 |
| Порядок сортировки | ID по возрастанию или убыванию | По возрастанию |

Форма настроек реализована на Twig. Значения валидируются и сохраняются через API конфигурации NGCMS.

## Использование

Активируйте плагин и откройте его настройки в административной панели. Для массового удаления отметьте нужные комментарии и отправьте форму. Список включает комментарии, связанные с опубликованными новостями.

Тексты интерфейса находятся в `lang/russian/config.ini` и `lang/english/config.ini`. События загрузки списка и удаления записываются через `ng-helpers` в `cache/logs/show_comments.log`.
