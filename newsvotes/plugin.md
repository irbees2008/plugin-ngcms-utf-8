# Опросы в новостях

`newsvotes` добавляет к новости один опрос с вариантами ответов. Опрос создаётся при добавлении или редактировании новости и отображается на её странице. Отдельной глобальной страницы настроек нет: параметры задаются для каждого опроса в форме новости.

## Возможности

- Создание вопроса и списка ответов при добавлении новости.
- Редактирование вопроса, списка ответов и доступа к голосованию.
- Удаление опроса или сброс его результатов.
- Ограничение голосования зарегистрированными пользователями, гостями или обеими группами.
- Отображение числа голосов и доли ответов в виде прогресс-полос.
- Русская и английская локализации интерфейса.

## Установка и подключение шаблонов

1. Установите и активируйте плагин через менеджер плагинов. Установщик добавляет поле `nvote` к таблице новостей и создаёт таблицы опросов.
2. В шаблоне формы добавления новости активной административной темы выведите поле плагина, например рядом с другими полями вкладки «Дополнительно»:

   ```twig
   {% if pluginIsActive('newsvotes') %}
       {{ plugin.newsvote }}
   {% endif %}
   ```

3. В шаблоне редактирования новости добавьте:

   ```twig
   {% if pluginIsActive('newsvotes') %}
       {{ plugin.newsvote_edit }}
   {% endif %}
   ```

   В стандартной теме это шаблоны формы добавления и редактирования новости в `engine/skins/default/tpl/news/`. Плагин не изменяет файлы темы автоматически.

4. В шаблоне полной новости выведите опрос. Для Twig-шаблона используйте `{{ newsvote }}`, для совместимого шаблона старого формата — `{newsvote}`.
5. При необходимости добавьте оформление в CSS темы:

   ```css
   .bonus_entry_progress {
       width: 50%;
   }

   .bonus_entry_bar {
       height: 5px;
       border: 1px solid;
   }
   ```

Плагин использует шаблоны из `tpl/skins/default/`. Их можно адаптировать под оформление темы, сохраняя имена и переменные шаблонов.

## Работа с голосами

- Один IP-адрес может проголосовать один раз в каждом опросе.
- Режим доступа хранится в поле `whovote`: `1` — только зарегистрированные пользователи, `2` — только гости, `3` — обе группы.
- Повторный голос с уже зарегистрированного IP не учитывается.
- После сброса результатов удаляются записи о голосах и обнуляются счётчики ответов.
- Если в опросе пока нет голосов, проценты ответов отображаются как `0`, без деления на ноль.

## Локализация

Подписи интерфейса добавления/редактирования новости и опроса находятся в `lang/<language>/main.ini`. Сообщения установщика и удаления — в `lang/<language>/config.ini`. В комплект входят каталоги `lang/russian/` и `lang/english/`.

## Данные и удаление

Установщик создаёт таблицы `newsvote`, `newsanswer`, `newsvoted` и добавляет поле `nvote` в таблицу новостей. Деинсталлятор удаляет эти таблицы и поле; связанные опросы, ответы и записи о голосах при этом удаляются.

Основной обработчик фильтра находится в `newsvotes.php`. Плагин использует API фильтров новостей NGCMS и не требует отдельного конфигурационного файла.
