# ShowPic — фото на отдельной странице

Плагин регистрирует страницу `showpic` и выводит выбранный файл из каталога изображений сайта. Для содержимого используется шаблон плагина `tpl/pic.tpl`; при наличии одноимённого шаблона в активной теме он может переопределить стандартный.

## Установка

1. Разместите каталог в `engine/plugins/showpic`.
2. Активируйте плагин в панели управления.
3. Добавьте ссылку на страницу показа изображения в собственный шаблон или код, передав параметры `f` (папка внутри каталога изображений; можно оставить пустой) и `p` (имя файла).

Пример генерации ссылки из PHP:

```php
$url = generateLink(
    'core',
    'plugin',
    ['plugin' => 'showpic'],
    ['f' => $folder, 'p' => $filename]
);
```

Плагин не требует изменений файлов ядра. Старый способ автоматической подстановки `{prevurl}` в менеджере файлов требовал ручного редактирования `file_managment.php` и больше не является частью инструкции по установке.

## Безопасность и ошибки

Плагин проверяет, что запрошенный файл существует внутри каталога изображений. Переходы по `..`, абсолютные пути и имена с разделителями отклоняются. Ссылки на файлы кодируются для URL, значения `src` и `alt` экранируются для HTML.

При пустых или неверных параметрах выводится локализованное сообщение. Если файл не найден, выводится отдельное сообщение об отсутствии изображения.

## Локализация

Русские и английские сообщения находятся в `lang/russian/main.ini` и `lang/english/main.ini`.
