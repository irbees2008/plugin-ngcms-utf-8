# Cloudflare Turnstile Plugin для NGCMS

Современная невидимая защита форм от ботов с Cloudflare Turnstile. Прощай, reCAPTCHA!

## 🎯 Что такое Cloudflare Turnstile?

**Turnstile** — это революционная альтернатива традиционным CAPTCHA от Cloudflare.

### 🚀 Главная особенность

**Пользователи НЕ решают головоломки!**

Вместо этого Turnstile:

- Запускает неинтрузивные JavaScript-тесты в браузере
- Собирает данные о поведении и окружении браузера
- Отправляет сигналы на сервер Cloudflare
- Умные алгоритмы определяют, человек или бот
- **Всё происходит за доли секунды в фоновом режиме**

### ✨ Ключевые преимущества

| Характеристика                 | reCAPTCHA                | Cloudflare Turnstile            |
| ------------------------------ | ------------------------ | ------------------------------- |
| **Видимость для пользователя** | Постоянно мешает         | ✅ Невидимая (90%+ случаев)     |
| **Конфиденциальность**         | Отслеживание для рекламы | ✅ Не отслеживает между сайтами |
| **Cookie**                     | Используются             | ✅ Не используются              |
| **Скорость проверки**          | 2-5 секунд               | ✅ 0.2-0.5 секунды              |
| **UX**                         | Раздражает пользователей | ✅ Не прерывает flow            |
| **Стоимость**                  | Бесплатно до лимита      | ✅ Бесплатно без ограничений    |
| **Интеграция**                 | Сложная                  | ✅ 5 минут                      |

## 📦 Установка

### Шаг 1: Получение ключей

1. Зайдите на [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. Перейдите в раздел **Turnstile** (даже если ваш сайт не на Cloudflare!)
3. Нажмите **Add site**
4. Укажите домен вашего сайта
5. Выберите тип виджета:
   - **Managed** - рекомендуется, баланс между защитой и UX
   - **Non-Interactive** - только для сайтов с высоким трафиком
   - **Invisible** - максимальная невидимость
6. Скопируйте **Site Key** и **Secret Key**

### Шаг 2: Установка плагина

1. Убедитесь, что установлен плагин `ng-helpers`
2. Скопируйте папку `ng-turnstile` в `engine/plugins/`
3. Активируйте плагин в админ-панели
4. Перейдите в настройки плагина
5. Вставьте **Site Key** и **Secret Key**
6. Настройте параметры (по желанию)
7. Сохраните

**Готово! Формы защищены.**

## ⚙️ Настройки

### Ключи Cloudflare Turnstile

- **Site Key** - публичный ключ для отображения виджета
- **Secret Key** - секретный ключ для проверки токена на сервере

### Настройки виджета

#### Тема оформления

- **Автоматически** - подстраивается под тему вашего сайта
- **Светлая** - светлый виджет
- **Темная** - темный виджет

#### Размер виджета

- **Обычный** (300x65px) - стандартный размер
- **Компактный** (150x140px) - для мобильных устройств

#### Режим отображения

- **Always** - виджет всегда виден (рекомендуется)
- **Execute** - виджет появляется при выполнении проверки
- **Interaction-only** - виджет показывается только при подозрительной активности

### Основные настройки

- **Только для гостей** - показывать капчу только неавторизованным пользователям

## 🎨 Интеграция с темами

Плагин автоматически добавляет виджет в формы через фильтры.

### Автоматическая интеграция

Поддерживаются формы:

- ✅ Регистрация пользователей
- ✅ Комментарии
- ✅ Обратная связь (feedback)

### Ручная интеграция

Для добавления в кастомные формы используйте переменную `{{ turnstile_widget }}`:

```twig
<form id="my-form" method="post" action="/submit">
    <!-- Ваши поля формы -->

    {{ turnstile_widget|raw }}

    <button type="submit">Отправить</button>
</form>
```

## 🔧 Как это работает?

### Фронтенд

1. JavaScript API Turnstile загружается автоматически
2. Виджет рендерится в форме с вашим Site Key
3. При загрузке страницы Turnstile начинает сбор данных:
   - Информация о браузере и устройстве
   - Движения мыши и взаимодействия
   - JavaScript вызовы и тайминги
   - Особенности окружения
4. При отправке формы генерируется токен `cf-turnstile-response`
5. Токен автоматически добавляется в POST-данные

### Бэкенд

1. Плагин перехватывает отправку формы через фильтры
2. Извлекает токен `cf-turnstile-response` из POST
3. Отправляет запрос на `siteverify` API Cloudflare:
   ```
   POST https://challenges.cloudflare.com/turnstile/v0/siteverify
   {
     "secret": "ваш_secret_key",
     "response": "токен_пользователя",
     "remoteip": "IP_адрес"
   }
   ```
4. Получает ответ:
   ```json
   {
     "success": true,
     "challenge_ts": "2026-01-21T12:00:00Z",
     "hostname": "example.com"
   }
   ```
5. Если `success: true` - пропускает форму
6. Если `success: false` - блокирует с сообщением об ошибке

## 📊 Логирование

Все проверки логируются в `engine/cache/logs/plugins.log`:

```

[WARNING] ng-turnstile: Comment blocked - Invalid token
[ERROR] ng-turnstile: cURL error - Connection timeout
```

## 🔐 Безопасность

### Что проверяет Turnstile?

- **Окружение браузера** - user-agent, язык, часовой пояс
- **JavaScript выполнение** - наличие и поведение JS
- **Взаимодействия** - естественные движения мыши
- **Время загрузки** - нормальная ли задержка
- **Отпечатки устройства** - характеристики без cookie
- **Сетевые паттерны** - анализ через Cloudflare сеть

### Уровни защиты

По умолчанию Turnstile использует режим **Managed**:

- Блокирует очевидных ботов немедленно
- Для подозрительных показывает интерактивный challenge
- Для человека проходит незаметно

## 💡 Советы по использованию

### Для максимальной невидимости

1. Выберите режим **Managed** при создании сайта в Cloudflare
2. Установите `appearance = "interaction-only"` в настройках
3. Используйте тему `auto` для адаптации под дизайн

### Для максимальной защиты

1. Выберите режим **Managed** (не Invisible!)
2. Установите `appearance = "always"`
3. Включите "Только для гостей"
4. Мониторьте логи на предмет атак

### Для лучшего UX

1. Размещайте виджет **перед** кнопкой отправки
2. Не добавляйте дополнительные проверки (email verification и т.д.)
3. Показывайте понятные сообщения об ошибках
4. Используйте компактный размер на мобильных

## 🐛 Устранение проблем

### Виджет не появляется

1. Проверьте, что JavaScript API загружается (смотрите в консоли браузера)
2. Убедитесь, что Site Key правильный
3. Проверьте, что домен добавлен в настройках Cloudflare

### Проверка всегда не проходит

1. Проверьте Secret Key
2. Убедитесь, что время на сервере синхронизировано
3. Проверьте, что cURL или allow_url_fopen доступны
4. Смотрите логи: `tail -f engine/cache/logs/plugins.log`

### Виджет виден на каждой форме

Это нормально! Turnstile показывается, но:

- Для большинства пользователей проверка проходит мгновенно
- Не требуется никаких действий
- Не прерывает процесс заполнения формы
