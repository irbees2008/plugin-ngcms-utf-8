# Плагин «Похожие новости» (SCN)

Плагин формирует блок ссылок на другие опубликованные новости, относящиеся хотя бы к одной категории текущей новости. Текущая новость исключается из результата. Вывод добавляется в переменную шаблона `plugin_scn` на странице полной новости.

## Установка и включение

1. Поместите каталог плагина в `engine/plugins/scn`.
2. В панели управления откройте управление плагинами и активируйте «Похожие новости».
3. В настройках плагина задайте количество записей, сортировку и формат вывода.
4. Добавьте `{plugin_scn}` в шаблон полной новости в том месте, где должен отображаться блок.

Плагин не создаёт таблиц и не изменяет базу данных. Установка и удаление через отдельные скрипты не требуются.

## Настройки

| Параметр | Описание |
|---|---|
| Количество новостей | Максимальное количество похожих новостей. Значение должно быть не меньше 1; по умолчанию используется 5. |
| Сортировка | Случайный порядок, дата или ID по возрастанию/убыванию. По умолчанию — сначала новые. |
| Формат вывода | Ссылки по умолчанию или заданный администратором шаблон одной новости. |
| Шаблон одной новости | Строка, повторяемая для каждой найденной новости в пользовательском режиме. |

Доступны следующие варианты сортировки:

| Значение | Порядок |
|---:|---|
| 0 | Случайный |
| 1 | Дата публикации, новые сначала |
| 2 | Дата публикации, старые сначала |
| 3 | ID по убыванию |
| 4 | ID по возрастанию |

## Переменная и шаблон

Для вывода блока в шаблоне полной новости используйте `{plugin_scn}`. Если похожих записей нет, переменная будет пустой.

В режиме пользовательского шаблона одна запись формируется из текста настройки. Поддерживаются подстановки:

| Переменная | Значение |
|---|---|
| `{link}` | URL полной новости |
| `{title}` | Заголовок новости |
| `{date}` | Дата публикации в формате `дд.мм.гггг` |
| `{author}` | Автор |
| `{com}` | Количество комментариев |
| `{views}` | Количество просмотров |

Пример шаблона записи:

```html
<div class="related-news"><a href="{link}">{title}</a> <small>{date}</small></div>
```

В режиме ссылок по умолчанию каждая найденная новость выводится отдельной ссылкой.

## Локализация

Настройки плагина имеют русскую и английскую локализации в `lang/russian/config.ini` и `lang/english/config.ini`.
