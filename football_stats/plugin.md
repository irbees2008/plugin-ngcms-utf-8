# Футбольная статистика

Плагин хранит сведения о странах, командах, игроках, чемпионатах, матчах и голах. На сайте он формирует турнирные таблицы, списки матчей и бомбардиров, страницы команд, игроков и турниров, а также рейтинги UEFA/FIFA.

## Установка и удаление

Установка выполняется через менеджер плагинов NGCMS. `install.php` создаёт восемь таблиц с префиксом сайта и регистрирует URL-команды. `uninstall.php` удаляет эти же таблицы и команды плагина:
`football_countries`, `football_teams`, `football_championats`, `football_teams_championats`, `football_games`, `football_players`, `football_games_goals` и `football_leagues`.

Для настройки используется штатная страница плагина в `admin.php?mod=extra-config&plugin=football_stats`; отдельный модуль в `engine/actions/` не требуется. Не применяйте инструкции из прежнего `instruction.txt`: они предлагали изменять файлы ядра и относились к старому способу установки.

## Настройки

Настройки находятся в `config.php` и выводятся Twig-шаблоном `tpl/config/settings.tpl`.

- Кэширование и срок его действия (`cache`, `cacheExpire`).
- Число элементов на страницах, число бомбардиров и элементов рейтинга.
- Список стран для главной страницы (`championats`, через запятую).
- URL и дисковый путь фотографий, путь загрузки изображений трансляций.
- Лимиты голов и карточек, диапазон дат и сдвиг дней для выбранных матчей.
- `country_views` — JSON-объект, сериализуемый плагином в формат, используемый сайтом. Ключ объекта — alias страны, значение содержит `v` (показывать блок) и `n` (номер тура), например:

  ```json
  {"ukraine":{"v":1,"n":5}}
  ```

- `league_views` — JSON-массив настроек турнирных блоков. Элементы должны содержать поля, используемые шаблонами: `name`, `id`, `v`, `t`, `champt_type`, `champt_start`, `champt_end`, `league_name`, `champt_name`.

При сохранении JSON проверяется на корректность. Хранимые ранее сериализованные настройки `country_views` и `league_views` автоматически показываются в JSON-представлении и записываются обратно в совместимом формате PHP-сериализации.

## Страницы и URL

Плагин регистрирует страницы `football`, `team`, `player`, `match`, `add-fine`, `add-fine1`, `get-players`, `league`, `uefa_team`, `uefa_country`, `fifa_country`, `today`, `matches` и `scorers_page`.

Основные ЧПУ-шаблоны:

| Страница | Шаблон URL |
|---|---|
| Страна и таблица чемпионата | `/football/country/{name}` |
| Команда | `/team/{name}` |
| Игрок | `/player/{id}` |
| Матч | `/match/{id}` |
| Кубок или лига | `/football/{type}/{year_start}[-{year_end}]` |

Доступные команды ЧПУ и их параметры регистрируются установщиком плагина. Ссылки на рейтинги, матчи и бомбардиров следует строить через функции NGCMS для генерации ссылок плагинов.

## Шаблоны сайта

Шаблоны сайта находятся в `tpl/main/`. Переменные, которые можно использовать в основном шаблоне сайта:

- `{championat_<alias>}` — таблица последнего чемпионата указанной страны.
- `{round_<alias>}` — выбранный тур указанной страны.
- `{uefa_teams}`, `{uefa_countries}`, `{fifa_countries}` — блоки рейтингов.

Для блока `{championat_<alias>}` задайте alias страны в параметре `championats`; для блока тура настройте соответствующую запись в `country_views`. Логотипы каналов находятся в `inc/channel.php`, фотографии — в каталоге, заданном настройками плагина.

Интерфейс настроек использует Twig. Вывод существующих страниц продолжает поддерживать исторические шаблоны `$tpl` плагина, включая шаблоны с Twig-условиями; их массовая замена не требуется для установки и должна выполняться отдельно при адаптации конкретного оформления сайта.

## Локализация и совместимость

Русские строки находятся в `lang/russian/`. Основная логика страниц — `football_stats.php`; SQL-схема установки и удаления должна оставаться согласованной между `install.php` и `uninstall.php`.

Плагин использует API NGCMS для регистрации страниц, параметров плагина, локализации и кэширования. Для Twig-шаблонов требуется сборка движка не ниже `2020731`.
