# Кеширование запросов к базе данных

Плагин подключается к штатному адаптеру `NGLegacyDB` при обработке действия `core`. Он не подменяет глобальный `$mysql`, не открывает отдельное соединение и не обходит `NGPDO` для запросов, которые не обслуживаются из кеша.

## Что кешируется

- Результаты методов `select()`, `record()` и `result()`, если SQL-запрос начинается с `SELECT`.
- Результаты, включая пустой массив и `false`; ошибки базы данных с результатом `null` не сохраняются.
- Записи хранятся в файловом кеше сайта с заданным временем жизни.
- На попадании в кеш SQL повторно не выполняется, поэтому запрос не попадает в список SQL-запросов `NGPDO`.

Для снижения риска устаревших или персональных данных не кешируются запросы с блокировками, динамическими функциями времени/случайных значений, пользовательскими SQL-переменными, множественными выражениями и таблицами/полями пользователей, сессий, авторизации, прав, токенов и CAPTCHA.

## Сброс кеша

После любого SQL-оператора, который может изменить данные или структуру БД, плагин меняет поколение кеша. Старые записи сразу перестают использоваться, включая кеш в других PHP-процессах. Операторы вроде `SET`, `SHOW` и `SELECT` не сбрасывают кеш.

Кеширование отключено, если срок хранения равен `0`. Максимальный срок — 1440 минут. Изменения в базе, сделанные в обход этого адаптера (например, внешним скриптом или напрямую из другого приложения), обнаруживаются только по истечении срока хранения.

## Установка и настройка

1. В разделе управления плагинами установите/активируйте `dbcache`. Плагин добавляет обработчик `core` через метаданные `plugin.md`; вручную менять `engine/core.php` не нужно.
2. Если плагин уже был активирован до обновления, выключите и снова включите его, чтобы движок перечитал список действий.
3. В настройках укажите срок кеширования в минутах. Значение `0` отключает кеш.

Для работы файлового кеша PHP-процессу требуется право записи в каталог кеша сайта. Ошибки доступа записываются в PHP error log; при недоступности кеша запрос выполняется напрямую к базе.

## Ограничения

Кешируется только полностью собранный результат `select()`, `record()` или `result()`. Метод `query()`, возвращающий объект запроса для последующей выборки строк, не кешируется.
