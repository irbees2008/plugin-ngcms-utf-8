# Социальные закладки

Плагин добавляет в полную новость ссылки для её публикации в настроенных социальных сервисах. Ссылки и список сервисов настраиваются из административной панели. Сервис можно включать и отключать, менять порядок, подпись, URL-шаблон и иконку.

## Использование

В шаблоне полной новости (`news.full.tpl`) выведите блок:

```twig
{plugin_social}
```

Если нет активных сервисов, переменная остаётся пустой.

## Административные настройки

В общих настройках задаются:

- источник шаблона и иконок: активная тема сайта или встроенный шаблон плагина;
- скин плагина;
- кеширование HTML блока и срок его хранения;
- ручная очистка кеша.

Список сервисов позволяет добавить, редактировать, включить/выключить, удалить и переместить сервис, а также восстановить стандартный набор. Восстановление заменяет весь текущий список.

В URL сервиса поддерживаются подстановки:

| Подстановка | Содержимое |
|---|---|
| `%title%` | Заголовок новости, URL-кодированный |
| `%content%` | Краткое содержание новости до 200 символов, URL-кодированное |
| `%link%` | Абсолютный URL новости, URL-кодированный |

При сохранении разрешены только URL с протоколами HTTP и HTTPS. Иконки выбираются из файлов изображений доступного скина.

Стандартный набор: Facebook, X, ВКонтакте, Одноклассники, LinkedIn, Reddit, Telegram и WhatsApp. Изначально все сервисы отключены.

## Шаблоны и иконки

Шаблон списка: `tpl/skins/<skin>/social.tpl`. Он обрабатывается Twig и получает:

- `home` — URL сайта;
- `entries` — массив активных сервисов.

Поля элемента `entries`:

- `url` — URL сервиса с подстановками;
- `title` — заголовок новости;
- `desc` — подпись сервиса;
- `img` — абсолютный URL иконки или пустая строка;
- `has_img` — признак доступной иконки.

Строковые значения элемента экранируются для HTML до передачи в Twig, так как движок использует Twig без глобального автоэкранирования. В пользовательском шаблоне не применяйте к этим полям повторное HTML-экранирование или фильтр `raw`.

При источнике «Активная тема сайта» плагин ищет шаблон и иконки в `templates/<theme>/plugins/social/`, затем использует файлы плагина как резервный вариант. Иконки плагина находятся в `tpl/skins/<skin>/images/`; если скин отсутствует, используется `default`.

## Кеширование

Кешируется сформированный HTML. Ключ учитывает данные новости, активные сервисы, скин, тему и язык, чтобы изменения записи или настроек не возвращали устаревший блок. Изменения настроек списка и сервисов также очищают кеш.

## Bitly

Старая интеграция использовала снятый с поддержки Bitly API v2 и не включена в текущую версию. Короткий URL при желании можно указывать в настройках стороннего сервиса отдельно; плагин не выполняет внешние запросы к сокращателям.

## Локализация

Интерфейс настроек переведён на русский и английский языки: `lang/russian/config.ini` и `lang/english/config.ini`.
