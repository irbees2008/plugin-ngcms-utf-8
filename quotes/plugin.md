# Цитатник (NG Quotes)

Плагин NGCMS для публикации цитат, пользовательского добавления записей и показа случайной цитаты в блоке.

## Метаданные плагина

Поля манифеста NGCMS перенесены в front matter этого файла; отдельный файл `version` не используется.

## Возможности

- Список одобренных цитат с сортировкой по дате.
- Постраничная навигация, отдельная страница цитаты и RSS.
- Добавление цитат зарегистрированными пользователями; публикация может требовать одобрения администратора.
- Импорт цитат из UTF-8 TXT-файла, по одной цитате в каждой строке.
- Блок со случайной цитатой.
- Управление цитатами в панели администратора: добавление, редактирование, удаление, одобрение и массовые действия.
- Поддержка форматирования NGCMS: HTML formatter, BBCode, смайлики и скрытые блоки.
- Кэширование списка цитат.
- Уведомления после действий через общий `/lib/notify.js`.

## Требования

- NGCMS с поддержкой плагинов и таблиц базы данных MySQL.
- PHP 8.0 или новее.

PHP-файлы плагина обновлены для PHP 8: устаревшая интерполяция переменных заменена, генерация даты RSS переведена на `gmdate()`, а обращения к необязательным параметрам и выборкам без записей защищены от ошибок типов и неопределённых индексов.

## Установка

1. Разместите каталог плагина в каталоге плагинов NGCMS.
2. Откройте Админка → Плагины → `quotes` → Установить.
3. Выполните установку через панель NGCMS. Установщик создаёт или обновляет таблицу `*_quotes` в `utf8mb4`, регистрирует URL-обработчики и задаёт начальные параметры. При повторном применении он переводит существующую таблицу на `utf8mb4`.
4. Добавьте Twig-переменную `{{ quotes_block|raw }}` в `main.tpl` активной темы, если нужно выводить случайную цитату вне страницы цитатника.
5. Для пакетной загрузки откройте вкладку «Импорт из файла» в настройках плагина и выберите UTF-8 TXT-файл: одна непустая строка — одна одобренная цитата. Максимум 2 МиБ и 5000 строк за импорт.

Установщик задаёт, в частности, следующие значения по умолчанию: 5 цитат на странице, 10 цитат на странице администрирования, ограничение длины 80 символов, перенаправление через 5 секунд; кэш выключен.

Русская и английская локализации административного интерфейса находятся в `lang/russian/config.ini` и `lang/english/config.ini`.

## Страницы и обработчики

| URL/обработчик | Назначение |
|---|---|
| `quotes` | Список цитат; сортировка `top`/`low` и параметр страницы |
| `quotes/show?id=<id>` | Просмотр одной одобренной цитаты |
| `quotes/add` | Форма добавления цитаты для вошедшего пользователя |
| `quotes/rss` | RSS 2.0 лента |
| индексный блок | Вывод случайной цитаты через Twig-переменную `{{ quotes_block|raw }}` |

При недоступности собственного URL-обработчика плагин использует стандартные ссылки NGCMS на страницу плагина.

## Настройки

- **Источник шаблонов (`localsource`)** — шаблоны сайта или каталог плагина.
- **Максимум символов (`max_char`)** — максимальная длина цитаты; `0` отключает ограничение.
- **Количество цитат (`count`)** — записей на странице.
- **Задержка перенаправления (`redirect_delay`)** — задержка сообщений после действий.
- **Формат даты (`date`)** — формат даты цитаты.
- **Описание (`description`) и ключевые слова (`keywords`)** — метаданные страницы и RSS.
- **Случайный блок (`rand`)** — лёгкий выбор по случайному ID или случайная сортировка SQL.
- **Количество в админке (`adm_count`)** — число строк на странице управления.
- **Кэш (`cache`, `cacheExpire`)** — включение кэша и срок его действия в секундах.

## Шаблоны

Основные шаблоны находятся в `tpl/`:

- `showquotes.tpl`, `shortquotes.tpl` — список цитат и его элементы;
- `fullquotes.tpl` — отдельная цитата;
- `addquotes.tpl` — форма добавления;
- `block/quotes_block.tpl`, `block/show_block.tpl` — блок случайной цитаты;
- `config/` — формы управления в админ-панели.

При выборе источника «Шаблон сайта» NGCMS ищет шаблоны плагина в активной теме; при выборе «Плагин» используются файлы из каталога `tpl/` плагина.

### Вывод блока случайной цитаты

Вставьте в `templates/<активная-тема>/main.tpl`:

```twig
{{ quotes_block|raw }}
```

`quotes_block` уже содержит HTML, сформированный Twig-шаблонами плагина, поэтому для вывода разметки нужен фильтр `raw`.

Голосование удалено. Если плагин был установлен ранее, его старые поля рейтинга и таблица `*_quotes_flood` не удаляются автоматически, чтобы не выполнять разрушительную миграцию; текущая версия их не использует.
